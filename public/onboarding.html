Mural

Um kanban montado a partir das reações de uma conversa do Teams. Três passos e o quadro está de pé.

1

Claude Code instalado

verificando…

O Mural usa o Claude Code para ler o Teams — ele é obrigatório. Instale em claude.com/claude-code, feche e abra este servidor de novo.

2

Conta Microsoft conectada

aguardando o passo 1

O Mural não pede nem guarda sua senha. Quem autentica é o conector Microsoft 365 do Claude Code — aqui só perguntamos quem já está logado. Leva cerca de 20 segundos.

3

Escolher a conversa

aguardando o passo 2

Canais não podem ser listados: a API da Microsoft não oferece essa rota para conectores. O link resolve porque carrega o time, o canal e os nomes de ambos.

Lista chats 1:1, grupos e reuniões. Costuma levar de 2 a 3 minutos — o Teams entrega os chats em páginas e cada uma é uma ida à API.
